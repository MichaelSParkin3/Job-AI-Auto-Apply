## Story
As the automation architect,
I want the agent to resolve missing field answers using a governed LLM fallback,
so that Lever applications can be completed end-to-end even when the profile lacks pre-saved responses.

## Acceptance Criteria
1. **Answer Precedence Contract** — Implement `AnswerOrchestrator` (Python service) exposing `draft_answer(request: AnswerRequest) -> AnswerOutcome` that enforces precedence `profile deterministic -> resume-derived fact -> cached run answer -> LLM draft`. Responses include `{value, source, confidence, rationaleDigest, policy}`. Provenance is persisted to `run.json.answers[]` and `runs/<id>/answers/<fieldId>.json`. [Source: docs/prd/epic-5-full-ai-form-filling-assisted-submit.md#story-53--ai-answer-orchestrator--drafting-pipeline][Source: docs/architecture/ai-answer-orchestration.md#answerorchestrator][Source: docs/architecture/data-models.md#draftedfieldanswer]
2. **LLM Prompt/Response Schema** — Define `AnswerDraftRequest`/`AnswerDraftResponse` pydantic models capturing field metadata, resume/profile snippets, validation rules, and locale/timezone hints. Enforce schema validation, max token budget, and redaction before sending to OpenRouter. Invalid or low-confidence (< policy threshold) responses trigger deterministic fallback with `reason=validation_failed|low_confidence`. [Source: docs/prd/epic-5-full-ai-form-filling-assisted-submit.md#story-53--ai-answer-orchestrator--drafting-pipeline][Source: docs/architecture/ai-answer-orchestration.md#answerdraftrequest][Source: docs/architecture/security-and-performance.md#ai-answer-governance]
3. **Telemetry & Artifacts** — Emit `AI_FIELD_DRAFTED`, `AI_FIELD_DRAFT_FAILED`, and `AI_FIELD_DRAFT_SKIPPED` events with model, latency, token usage, confidence percentile, and fallback reason. Persist reviewer-friendly markdown summaries (value length hashes only) under `runs/<id>/answers/summary.md` and register them in `run.json`. [Source: docs/prd/epic-5-full-ai-form-filling-assisted-submit.md#story-53--ai-answer-orchestrator--drafting-pipeline][Source: docs/architecture/ai-answer-orchestration.md#run-artifacts]
4. **Configuration & CLI Controls** — Extend global/profile config to include `automation.answerPolicies` (min confidence, allowSaveToProfile, allowLLMFallback). Expose CLI flags `--no-answer-llm`, `--min-answer-confidence`, and `--answer-model`. Document precedence (CLI > profile > global) and integrate with existing config loader. [Source: docs/prd/requirements.md#functional-fr][Source: docs/architecture/development-workflow.md#environment-configuration][Source: docs/architecture/ai-answer-orchestration.md#configuration]
5. **Executor Integration & Tests** — Autofill executor consumes orchestrator output when planning fills: approved deterministic answers bypass Browser-Use typing, LLM drafts feed the queued actions, and fallback marks fields for manual entry. Add pytest suites covering precedence, schema validation errors, timeouts, telemetry, and CLI overrides. Provide fixture data for two Lever variants plus a simulated network timeout. [Source: docs/prd/epic-5-full-ai-form-filling-assisted-submit.md#story-53--ai-answer-orchestrator--drafting-pipeline][Source: docs/architecture/core-workflows.md#ai-answer-generation-loop][Source: docs/architecture/testing-strategy.md]

## Dev Technical Guidance
- **Prompt Safety:** Reuse redaction helpers from decision logging (Story 4.4) and plan telemetry (Story 5.1) to hash value previews before logging or persisting prompts. Ensure tokens/timeouts align with OpenRouter quotas described in docs/architecture/security-and-performance.md.
- **Policy Evaluation:** Implement confidence thresholds as floats 0–1 with profile overrides; conversions to percentages happen only at presentation time to avoid rounding drift.
- **Error Handling:** Catch OpenRouter errors, network timeouts, and schema mismatches; emit `AI_FIELD_DRAFT_FAILED` with structured reasons while falling back to deterministic flows so automation never blocks on answer drafting.
- **Testing Strategy:** Use dependency injection to swap in a fake OpenRouter client returning canned responses; leverage pytest parametrization to cover each precedence path and CLI override combination.
- **Extensibility:** Design orchestrator API to support future models (OpenAI, local) by referencing provider name and version in telemetry; store provider metadata in artifact headers for audit.
